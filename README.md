# Flashlight Plus (Forge 1.20.1)
Add-on for Flashier Flashlights 1.2.0.
1. EMF compat – hands-up pose re-applied after EMF custom animations (needs EMF 3.x).
2. Flashlight in OFF hand turns off / can't be toggled while a non-pistol TACZ gun is in the MAIN hand.
3. ParCool – while a ParCool animation runs, arms follow ParCool and the first-person beam follows the arm.
Build: push to GitHub, Actions builds the jar (artifact "flashlightplus").
